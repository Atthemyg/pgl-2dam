## Tecnologías que se usaran en la asignatura:

### Desarrollo Web y Aplicaciones

- **JavaScript:** Es el lenguaje de programación fundamental de la web. Se utiliza para dar interactividad a las páginas web.

- **TypeScript**: Es una versión avanzada de JavaScript creada por Microsoft. Añade "tipado estático", lo que ayuda a detectar errores en el código antes de ejecutarlo, haciendo que los proyectos grandes sean más ordenados y fáciles de mantener.

- **React Native**: Es una librería de JavaScript creada por Facebook. Se usa para construir interfaces de usuario rápidas y modernas en la web, mediante componentes visuales reutilizables.


### Desarrollo de Aplicaciones Móviles

- **Expo**: Es una plataforma y conjunto de herramientas que facilita el desarrollo de aplicaciones para Android e iOS utilizando React Native.

### Desarrollo de Videojuegos y Entornos 3D

- **Unity**: Es uno de los motores de videojuegos más populares del mundo. Se usa para crear juegos en 2D y 3D, simulaciones y experiencias de realidad virtual.

- **Unreal Engine**: Es otro motor de videojuegos de gama alta, famoso por sus gráficos hiperrealistas. Se utiliza para juegos AAA, efectos visuales en el cine y arquitectura.

## Extensiones para VSCODE

- **ESLint**: Analiza el código en tiempo real para encontrar errores de sintaxis o malas prácticas en JavaScript y TypeScript antes de que rompan la aplicación.

- **TypeScript Nightly:** Da autocompletado avanzado, refactorización y detección de errores para TypeScript.

- **Prettier:** Organiza y da formato visual uniforme al código cada vez que se guarda un archivo.

- **Error Lens:** Muestra los mensajes de error y advertencias directamente en la misma línea de código, facilitando su lectura sin tener que pasar el ratón por encima.

- **ES7+ React/Redux/React-Native snippets:** Permite escribir código de React Native rápidamente usando atajos de teclado.

- **Expo Tools:** Añade soporte de autocompletado para los archivos de configuración de Expo y ayuda a depurar la app.
